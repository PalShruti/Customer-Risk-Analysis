# Customer Risk Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes customer churn and customer risk patterns.

The dashboard helps identify factors affecting customer churn, including:

- Internet Service Type
- Contract Type
- Payment Method
- Customer Charges
- Customer Support Tickets

## Tools Used

- Power BI
- DAX
- Power Query

## Dashboard Features

- KPI Cards
  - Total Customers
  - Churn Rate
  - Yearly Charges
  - Admin Tickets
  - Tech Tickets

- Interactive Filters
- Bar Charts
- Pie Charts
- Combo Charts
- Customer Churn Analysis

## Dashboard Preview

![Dashboard](Dashboard.png)

## Key Insights

- Customers with month-to-month contracts show higher churn rates.
- Fiber optic users have a higher churn rate compared to other internet services.
- Electronic check payment method is associated with higher churn.
- Contract duration has a significant impact on customer retention.
